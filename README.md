# GoSafe Frontend

Frontend application for **GoSafe – Intelligent Ride Safety Mediation Platform**.

GoSafe is a full-stack project focused on improving ride safety through route analysis, safety scoring, journey planning, and emergency assistance.

The frontend is being developed using **React.js** and will communicate with the GoSafe Spring Boot backend through REST APIs.

> 🚧 **Project Status:** In Development  
> The frontend is currently under active development. Features and backend integration will be added progressively.

---

## 🚀 About GoSafe

GoSafe is designed to help users make safer travel decisions by analyzing route-related factors and providing safety information.

The frontend will provide interfaces for features such as:

- User registration and login
- Journey planning
- Route selection
- Route safety score
- Interactive maps
- Journey details
- Captain/driver information
- SOS and emergency assistance
- User profile and journey management
